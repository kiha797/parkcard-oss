# 🚗 QR 주차번호판 (parkcard) — 전화번호 없는 주차 연락 카드 (오픈소스)

> 공개 오픈소스판입니다 (AGPL-3.0). 운영 사이트의 관리자 화면과 카드형 디자인은 포함되어 있지 않습니다.
> 설치 후 `wrangler.toml`의 데이터베이스 id·도메인 등을 자기 값으로 바꿔 쓰세요.

차 안에 둔 QR 카드를 찍으면 **차주 휴대폰으로 푸시 알림**이 가고,
차주가 알림을 눌러 "5분 안에 갈게요"를 고르면 **연락한 사람 화면에 바로 표시**됩니다.

- **전화번호를 아예 받지 않습니다.** 앱 설치도, 회원가입도 없습니다.
- 카드는 각자 **집 프린터로 출력**해서 씁니다.
- **Cloudflare Workers**에서 무료로 24시간 동작합니다 (서버 관리 없음).
- AGPL-3.0 라이선스. 누구나 자기 Cloudflare 계정에 설치해 쓸 수 있습니다 (수정해서 서비스하면 소스 공개 의무).

## 어떻게 동작하나

```
[차 안의 QR 카드] ──스캔──▶ 연락 화면 ──"차 빼주세요"──▶ Cloudflare ──웹 푸시──▶ 차주 휴대폰 알림
                                ▲                                                    │
                                └────────────── "5분 안에 갈게요" ◀── 알림 눌러 응답 ┘
```

| 문제 | 해결 |
|---|---|
| QR 인식이 잘 안 됨 | QR + **6자리 코드 직접 입력** 2중 경로. QR은 오류 복원 최고 등급(H), 큰 크기, 짧은 주소. 출력 요령은 [출력가이드.md](출력가이드.md) |
| 번호 노출, 개인정보 | 전화번호 대신 브라우저 **웹 푸시**만 사용 |
| 문자·050 비용 | 웹 푸시 + Cloudflare 무료 플랜 |
| 알림을 봤는지 모름 | 차주 응답이 연락한 사람 화면에 실시간 표시 |
| 밤늦은 알림 | 차주가 방해 금지 시간 설정. '급한 상황' 체크 시에만 전달 |
| 장난 알림 | 같은 사람 20초에 1번, 차주가 응답하지 않은 알림은 카드당 1시간에 10건까지 (응답을 주고받는 대화는 막지 않음) |
| 휴대폰 여러 대 | 한 카드에 기기 최대 10대 연결 |

## 사용 순서 (차주)

1. 알림을 받을 휴대폰으로 사이트 접속 → **내 카드 만들기**
2. **관리 화면 주소가 열쇠**입니다. 즐겨찾기 또는 홈 화면에 추가
3. **알림 켜기 → 테스트 알림**으로 확인
4. **출력 화면**에서 큰 카드(대시보드용)나 작은 스티커를 인쇄해 차에 두기

| 휴대폰 | 방법 |
|---|---|
| 안드로이드 | Chrome 또는 삼성 인터넷에서 바로 알림 켜기 가능 |
| 아이폰 | **iOS 16.4 이상**. Safari에서 **공유 → 홈 화면에 추가** 후, 홈 화면 아이콘으로 열어야 알림 켜기 가능 |

## Cloudflare에 설치하기 (처음 한 번)

준비물: Cloudflare 계정(무료), [Node.js](https://nodejs.org) LTS 버전, 이 저장소를 내려받은 폴더.
아래 명령은 모두 **이 폴더에서** 실행합니다.

### 1. 필요한 프로그램 설치

```bash
npm install
```

### 2. Cloudflare 로그인

브라우저가 열리면 Cloudflare에 로그인하고 **Allow**를 누릅니다.

```bash
npx wrangler login
```

### 3. 데이터베이스 만들기

```bash
npx wrangler d1 create parkcard
```

출력에 나오는 `database_id = "…"` 값을 복사해서 `wrangler.toml`의 `database_id`에 붙여 넣습니다.

### 4. 설정 바꾸기 (`wrangler.toml`)

- `VAPID_SUBJECT`: 본인 이메일로 (`mailto:내메일@example.com`). 애플·구글 푸시 서버가 요구합니다.
- **내 도메인 연결** (선택, 권장): 맨 아래 `[[routes]]` 두 줄의 `#`을 지우고 주소를 넣습니다.
  ```toml
  [[routes]]
  pattern = "p.내도메인.com"
  custom_domain = true
  ```
  - 도메인이 Cloudflare에 연결되어 있으면 DNS 설정은 자동으로 됩니다.
  - 이미 쓰고 있는 하위 도메인과 **겹치지 않는 이름**을 쓰세요.
  - **짧을수록 QR이 단순해져 잘 찍힙니다.** (예: `p.`, `pk.`)
  - 도메인을 안 쓰면 `parkcard.<계정이름>.workers.dev` 주소로 동작합니다.

### 5. 배포

```bash
npm run deploy
```

끝나면 출력에 주소가 나옵니다. 휴대폰으로 열어 **내 카드 만들기**부터 해 보세요.

### 코드를 고친 뒤 다시 배포

```bash
npm run deploy
```

> GitHub에 올릴 때마다 자동으로 배포하고 싶다면: Cloudflare 대시보드 → Workers & Pages → parkcard → Settings → Builds 에서 이 저장소를 연결하세요.

## 내 컴퓨터에서 실행해 보기

```bash
npm run dev
```

`http://localhost:8787` 에서 열립니다. 폰에서 푸시까지 시험하려면 https 주소가 필요하니 터널을 씁니다.

```bash
cloudflared tunnel --url http://localhost:8787
```

## 주의

- 푸시용 키(VAPID)는 처음 실행할 때 자동으로 만들어져 D1 데이터베이스에 저장됩니다. **데이터베이스를 지우면 키가 바뀌어 모든 기기의 알림이 끊깁니다.**
- 사용량: Cloudflare 무료 플랜(하루 요청 10만 건, D1 무료 한도) 안에서 개인·소규모는 충분합니다.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `src/index.js` | 모든 경로(라우트) |
| `src/webpush.js` | 웹 푸시 발송 (WebCrypto로 직접 구현, 외부 라이브러리 없음) |
| `src/views.js` | 화면 HTML |
| `migrations/` | D1 데이터베이스 테이블 |
| `public/sw.js` | 차주 기기에서 푸시를 받아 알림을 띄우는 서비스 워커 |
| `public/app.js` | 관리 화면의 알림 켜기/끄기/테스트 |
| `wrangler.toml` | Cloudflare 설정 |

## 저장하는 정보

카드 코드, 차량 번호 뒷 4자리, 방해 금지 시간, 기기의 푸시 주소, 알림 내용(90일 후 삭제), 전송 제한용 IP 해시(하루 후 삭제).
**전화번호·이름·전체 차량번호·위치는 저장하지 않습니다.** 카드를 삭제하면 바로 연락이 끊기고, 30일 뒤 모두 완전히 지워집니다.
